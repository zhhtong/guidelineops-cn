# 简历项目介绍（可直接改写）

## GuidelineOps-CN：中西医临床指南知识治理与 AI 可信性基础设施

面向中西医结合临床知识进入 AI 系统时“来源分散、版本易漂移、证据难追溯、审核责任不清”的问题，设计并实现了一套以 provenance-first 为核心的指南与共识知识治理原型。系统通过 PubMed/Crossref 适配器和 CNKI/万方合法导出文件，统一采集指南、专家共识及规范性文档元数据，使用 Pydantic 建立来源定位、证据等级、适用人群、中西医映射和审核状态等结构化知识单元；在 SQLite 中实现去重、质量报告、双人医学复核、审核事件审计、知识撤回、影响范围分析和 SHA-256 版本冻结。针对禁忌证、相互作用、特殊人群和肝肾功能异常等高风险用药信息，另建安全规则模型，禁止把剂量或患者个体化处方写入知识库；当医学初审与终审意见不一致时，系统会保留 `pending` 状态并升级至 `medical_chair`，避免把一次模型或人工操作误当成临床结论。

这个项目的临床意义不在于替代医生，而在于把临床指南转化为可核验、可回溯、可撤回的 AI 知识资产：研发团队能够定位每条陈述对应的原文页码/章节和版本，医学团队能够看到风险、审核人、分歧原因及受影响的下游映射，产品团队也能在上线前区分“元数据审核通过”和“医学知识已经批准”。项目同时保留明确边界：当前是研究和教学用途的知识工程原型，不宣称已经完成临床验证、医疗器械注册或真实世界诊疗效果评估。

## 简历精简版

负责设计并实现中西医临床指南知识治理原型 GuidelineOps-CN：整合 PubMed、Crossref 及 CNKI/万方合法导出数据，构建带原文定位、证据等级、中西医映射和版本信息的结构化知识单元；实现 SQLite 持久化、来源快照、去重、质量报告、双人医学审核、审计追踪、撤回/影响分析及 SHA-256 版本冻结；针对高风险用药建立禁忌证、相互作用和特殊人群安全规则，并通过终审分歧升级机制将不确定结论交由医学负责人裁决。该项目将临床规范转化为 AI 可消费且可追溯的知识资产，重点解决 AI 辅助诊疗中的证据可解释性、用药合规和持续更新问题。

> 面试表达建议：把“已实现的工程能力”和“尚未宣称的临床能力”分开说明，强调项目用于知识治理和研发协作，不把审核状态描述为疗效证据。
