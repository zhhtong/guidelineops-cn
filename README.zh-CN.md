# GuidelineOps-CN

GuidelineOps-CN 是一个面向研究与教育的循证指南运营基础项目。本初始版本
仅提供可安装的 Python 包和命令行入口；适配器及其他数据工作流尚未实现。

本项目仅供研究和教育使用，不是医疗器械，不提供医疗建议，也不得用于作出或
支持临床决策。任何真实世界的健康问题都应咨询合格专业人员并查阅原始来源。

## 安装与运行

需要 Python 3.11 或更高版本，以及 [uv](https://docs.astral.sh/uv/)：

```bash
uv sync
uv run guidelineops --help
```

当前命令仅显示项目帮助文本。后续功能实现后再补充相应文档。
